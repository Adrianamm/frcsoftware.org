Every programmer's end goal is to write code that does what they set out to do.
But almost inevitably we will mess up some part of the code at some point.
Debugging is the process of finding problems in code we have already written and fixing them.

## syntax errors

before the program runs, there's a program called a `compiler` that takes all the code you wrote and turns it into instructions a machine will understand.
if the compiler doesn't understand what some part of the code means, it will throw an error.
this is a **syntax error** because these errors occur
when you mess up the syntax of a language (the way it is written).
we say this error happens at `compile time` because
it happens when the compiler is translating the code, before it ever actually runs.
